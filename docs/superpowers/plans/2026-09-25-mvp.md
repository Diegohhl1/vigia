# Vigía MVP — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Monitorizar changelogs/pricing/ToS/deprecations de ~12 proveedores cloud/SaaS, clasificar cada cambio por impacto con un LLM local, y publicar sitio estático con historial + RSS + digest de Telegram. Alertas instantáneas cobradas quedan para post-MVP.

**Architecture:** Pipeline en tres etapas desacopladas por SQLite: (1) `fetch` — conector por tipo de fuente (RSS/Atom, página HTML) con ETag/hash para saltar checks sin cambios; (2) `classify` — diff textual normalizado + LLM local (Ollama) que devuelve un veredicto JSON validado (ruido|menor|precio|breaking) con justificación; (3) `publish` — sitio estático (página por proveedor + índice) y feed RSS + digest diario a Telegram vía bot existente. Un `run` orquesta las tres etapas; `systemd --user` lo programa.

**Tech Stack:** Python 3.12, SQLite (stdlib `sqlite3`), httpx, feedparser, beautifulsoup4, selectolax opcional, Ollama REST (`http://127.0.0.1:11434`), pytest, GitHub Pages para el sitio (post-MVP: dominio propio).

**Spec:** `Wiki/2026-09-25-origen-validacion.md` (veredictos y GO/KILL) + `AGENTS.md` (reglas: scraping ético, LLM local, sin secretos en git).

## Global Constraints

- Python 3.12, dependencias mínimas: `httpx`, `feedparser`, `beautifulsoup4`, `pytest`. Nada de frameworks web en el MVP.
- Toda petición HTTP: `User-Agent: vigia/0.1 (+https://github.com/Diegohhl1/vigia)` y respeto de `robots.txt`.
- LLM: solo Ollama local (`config.yaml` del proyecto apunta a `http://127.0.0.1:11434`); timeouts de 60s y fallback a `needs_review` si falla.
- La salida del LLM SIEMPRE se valida con un esquema estricto; veredicto inválido → `needs_review` (nunca inventar).
- Sin secretos en git; Telegram token via variable de entorno `VIGIA_TG_TOKEN`.
- Un commit por tarea, mensaje conventional (`feat:`, `test:`, `chore:`).
- Suite verde antes de cada push.

- [ ] **Step 4: Implementar `src/vigia/db.py`**

```python
import sqlite3

SCHEMA = """
CREATE TABLE IF NOT EXISTS providers (
  id INTEGER PRIMARY KEY, slug TEXT UNIQUE NOT NULL, name TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS sources (
  id INTEGER PRIMARY KEY, provider_id INTEGER NOT NULL REFERENCES providers(id),
  kind TEXT NOT NULL CHECK(kind IN ('rss','html')), url TEXT UNIQUE NOT NULL,
  selector TEXT, etag TEXT, last_hash TEXT, enabled INTEGER DEFAULT 1
);
CREATE TABLE IF NOT EXISTS snapshots (
  id INTEGER PRIMARY KEY, source_id INTEGER NOT NULL REFERENCES sources(id),
  taken_at TEXT NOT NULL, content_hash TEXT NOT NULL, content TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS changes (
  id INTEGER PRIMARY KEY, source_id INTEGER NOT NULL REFERENCES sources(id),
  detected_at TEXT NOT NULL, verdict TEXT NOT NULL
    CHECK(verdict IN ('noise','minor','pricing','breaking','needs_review')),
  score INTEGER NOT NULL DEFAULT 0, summary TEXT NOT NULL DEFAULT '',
  evidence TEXT NOT NULL DEFAULT '', diff_text TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS digests (
  id INTEGER PRIMARY KEY, period_start TEXT NOT NULL, period_end TEXT NOT NULL,
  sent_at TEXT, content TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_changes_source ON changes(source_id, detected_at);
"""

def init_db(conn: sqlite3.Connection) -> None:
    conn.executescript(SCHEMA)
    conn.commit()
```
